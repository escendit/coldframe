# packages/ts

TypeScript libraries.

| Folder | What | Arrives in |
| --- | --- | --- |
| `api-client/` | The REST client: `src/schema.ts` generated by `openapi-typescript` from [`packages/openapi`](../openapi), wrapped by `openapi-fetch` in `createColdframeClient({ baseUrl, accessToken, fetch? })` | Story 1.8 (`GET /sites`, `POST /sites`, `GET /sites/{siteId}`) |

Every folder here with a `package.json` joins the pnpm workspace. The design tokens
([`packages/design-tokens`](../design-tokens), `@coldframe/design-tokens`) are a workspace package
too; they sit outside this folder because they generate Swift and Kotlin as well as CSS and TypeScript. Tests live in [`tests/ts`](../../tests/ts).

## Regenerating the API client

After changing `packages/openapi/coldframe.openapi.json`, run

```sh
pnpm --filter @coldframe/api-client generate
```

and commit `packages/ts/api-client/src/schema.ts`. A test in `tests/ts/api-client` regenerates the
schema in memory and fails while the committed file is stale. Never write API types by hand; import
them from `@coldframe/api-client`.
