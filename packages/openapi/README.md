# packages/openapi

The REST contract, written before the code that serves it (AD-10). Nothing is here yet.

It starts in Epic 1 with the first Site endpoints and grows with every epic that adds endpoints.
The Device endpoints `POST /device/ingest` and `POST /device/heartbeat` arrive in Epics 3 and 4.

The Server is validated against this document in CI. Clients are generated from it.
